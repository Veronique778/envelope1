# Фиолетовая открытка 💜

## Структура

```text
wing_card/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── wings.png
    └── song.mp3
```

### Картинка крыльев

Положи PNG с прозрачным фоном в:

`assets/wings.png`

Желательно, чтобы оба крыла были на одной картинке:

`[ левое крыло ][ правое крыло ]`

Сайт автоматически разделит картинку на две части и будет анимировать крылья.

### Музыка

Положи песню в:

`assets/song.mp3`

Если файл называется иначе — измени `src` у `<audio>` в `index.html`.

### Текст

Весь текст открытки находится прямо в `index.html`. Ищи комментарии:

`ВОТ ЗДЕСЬ МЕНЯЙ ТЕКСТ`

После загрузки на GitHub открой `index.html` через GitHub Pages — сайт будет доступен другим людям по ссылке.
